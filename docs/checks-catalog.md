# Каталог перевірок (`web_studio v1`) та формула Need score

## 1. Розподіл категорій та ваг

| Категорія | Вага $W_c$ | Перевірки |
| :--- | :---: | :--- |
| Продуктивність (`performance`) | 20% | `PERF-01..05` (5 перевірок) |
| Мобільна версія (`mobile`) | 15% | `MOB-01..04` (4 перевірки) |
| SEO (`seo`) | 15% | `SEO-01..06` (6 перевірок) |
| Безпека (`security`) | 15% | `SEC-01..05` (5 перевірок) |
| Доступність (`accessibility`) | 10% | `A11Y-01..03` (3 перевірки) |
| Технології (`technology`) | 10% | `TECH-01..02` (2 перевірки) |
| Цілісність (`integrity`) | 10% | `INT-01..02` (2 перевірки) |
| Бізнес-елементи (`business`) | 5% | `BIZ-01..04` (4 перевірки) |
| **Разом** | **100%** | **31 перевірка** |

## 2. Статуси результату перевірки

- `pass` → бал дефекту $d_i = 0$
- `warning` → бал дефекту $d_i = 0{,}5$
- `fail` → бал дефекту $d_i = 1{,}0$
- `unavailable` → виключається з розрахунку (технічний збій)
- `not_applicable` → виключається з розрахунку (наприклад, `BIZ-03` для не-магазинів)

## 3. Формула Need score

Для кожної категорії $c$, у якій є хоча б одна оцінена перевірка $i \in \text{Evaluated}(c)$:
$$D_c = \frac{\sum_{i \in \text{Evaluated}(c)} v_i d_i}{\sum_{i \in \text{Evaluated}(c)} v_i}$$

Загальний скор обчислюється за оціненими категоріями $C_{\text{eval}}$:
$$S = \operatorname{round}\left(100 \cdot \frac{\sum_{c \in C_{\text{eval}}} W_c D_c}{\sum_{c \in C_{\text{eval}}} W_c}\right)$$

Якщо сумарна вага недоступних (`unavailable`) перевірок перевищує **40%**, аудит позначається як неповний (`partial_audit`), щоб уникнути хибного ранжування.

Рівні потреби:
- `0–24` — здоровий (`healthy`)
- `25–49` — помірний (`moderate`)
- `50–74` — слабкий (`weak`)
- `75–100` — критичний (`critical`)
